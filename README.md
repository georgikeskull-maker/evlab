# EVLAB — сайт evlab.ee

Публичный сайт [evlab.ee](https://evlab.ee) — экспресс-диагностика и PDF-сертификация тяговых батарей электромобилей и подключаемых гибридов в Таллине и Харьюмаа. Оператор — GVKFORGE OÜ.

## Состав
| Файл / папка | Назначение |
|---|---|
| `index.html` | главная страница |
| `tingimused.html`, `privaatsuspoliitika.html`, `ohutus.html` | условия, политика конфиденциальности, правила безопасности |
| `akt/` | страница акта-согласия |
| `ev-droid/` | виджет помощника на сайте (`ev-droid.js`, `ev-droid.css`, аудио) |
| `evlab-consent.js` | согласие на обработку данных при заявке |
| `CNAME` | домен `evlab.ee` для GitHub Pages |
| `robots.txt`, `sitemap.xml` | индексация |
| `favicon*`, `og-image*`, `logo.png` | иконки и изображения для соцсетей |

## Публикация
Сайт работает на GitHub Pages. Каждый push в ветку `main` сразу попадает на публичный сайт. Перед коммитом проверяйте, что в нём нет секретов и внутренних данных.

Репозиторий подключён как git-подмодуль в приватном проекте BatteryLab (папка `EVLAB/`), откуда и ведётся разработка.

## Локальный просмотр
Откройте `index.html` в браузере или запустите из папки проекта `python -m http.server 8000 --bind 127.0.0.1` и откройте `http://localhost:8000`. Сервер останавливайте после проверки.
